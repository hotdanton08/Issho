# Phase 4：聲音

日期：2026-10-07（Asia/Taipei）。使用者確認 Chrome 預覽縮放調整可用後授權繼續，依既定順序實作 Phase 4；Phase 5 AI Copy 尚未開始。

## 行為與實作

- 答對、答錯與完成練習播放不同的短音效，使用 Web Audio oscillator 自行合成；沒有外部音檔、官方教材音檔或新增依賴。
- 音效僅在有效提交一次答案及進入完成畫面時播放，開關 OFF 不建立 AudioContext。
- 題目尚未提交時沒有播放按鈕；提交後回饋區顯示 volume_up 圖示。手動點擊才播放完整正確句、語言 ja-JP；所有題型、答對與答錯都使用 example.correctSentence，永不讀出錯誤變體或填空句。
- 每次重播先取消前次語音，重新查詢已載入聲音，優先使用 ja-JP／日文聲音；未取得清單時保留 lang=ja-JP 交給系統選擇。
- 換題、重玩、離開會停止聲音；離開釋放 AudioContext。尚在 resume 的音效若被停止，不會稍後補播。
- 日文語音 OFF 隱藏播放圖示，不影響音效；音效 OFF 不影響手動語音。沿用原 App 設定、localStorage key 與預設 ON，不新增設定頁或播放速度選單。
- 不支援語音時顯示「此瀏覽器不支援語音播放」；播放錯誤顯示「暫時無法播放，請再試一次」。仍可繼續作答，換題清除提示；音效失敗安靜略過。
- 題庫、課程範圍、計分、10 題節奏與短用途提示維持既有規則。

語音呼叫、佇列取消及聲音清單依據 [MDN SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis)。Web Speech 的聲音由瀏覽器／裝置提供，本階段不承諾日文 TTS 一定可離線使用。

## 使用者試聽

1. 答對、答錯各一題，確認兩種短音效不同；完成 10 題後確認完成音效。
2. 作答前確認沒有喇叭；答錯後點喇叭，聽到的必須是完整正確句。用途／找錯也各試一次。
3. 連點喇叭應重播，不累積一串朗讀；播放途中按繼續或離開應停止。
4. App 設定關閉音效，作答與完成都應無音效，但喇叭仍可播放；關閉日文語音應無喇叭，音效仍可用。重新整理後開關保持。
5. 在手機實機試聽日文讀音與聲音大小；瀏覽器或系統缺少可用日文聲音時可能出現播放失敗提示。

## 限制與下一步

- 尚未進行手機實機試聽；自動測試可驗證呼叫內容與操作規則，不能證明系統實際輸出聲音或日文發音品質。
- 既有 vue-router rootDir 提示仍存在，與本階段聲音無關。
- 既有で／動作場所 sample 的第 18 課歸屬仍待教材核對；聲音功能不表示內容驗收通過。
- 下一階段為 Phase 5：一鍵複製整次練習給 AI；需使用者後續指示，不自動開始。

## 試聽回饋：語音正常但未聽到答題音效

使用者最初回報整句語音可播放，答題音效未聽到；當時尚需確認音效開關是否 ON。不自行重設或覆蓋保存的偏好；後續使用者已確認音效可聽見，詳見下節音色調整。

- 新增實際 Edge Web Audio 測試，保留原生 AudioContext／oscillator／gain，以 analyser 量測音訊波形。原始程式可產生訊號，這不等於使用者音效已正常出聲，因此尚不能確認根因。
- 原音效 peak gain=0.08、每音 150ms，較短且音量低；調整 peak gain=0.2、每音 240ms，保留短淡入淡出，加上 30ms 排程餘裕，讓答題／完成提示較容易聽見。
- 新的真實訊號測試要求 RMS 大於 0.04；測試驗證音訊圖輸出，不是系統喇叭或使用者聽感。
- 首次新增測試曾有括號語法錯誤而無法執行，已修正後重跑通過。
- 調整後 typecheck、23 項單元測試、8 項聲音相關瀏覽器測試、ESLint／Prettier 與 production SPA build 全部通過。
- 此次增強音量後，使用者已確認聽得到音效；新的音色是否合期待仍需確認，不能標記為完整實機驗收。

### 後續：改為清脆即時的提示聲

使用者已確認能聽到音效，但希望聲音清脆、即時，原音色不合期待。已將原先較長的正弦波旋律改為三角波短提示，2ms 淡入後快速衰減；答對為明亮上行雙音，約 170ms，答錯為中音下行雙音，約 140ms，完成為短上行四音，約 345ms。AudioContext 使用 interactive latency hint，起音排程餘裕從 30ms 減至 5ms；實際裝置延遲仍需試聽。

音效開關、TTS 與停止播放規則維持既有行為。本次 typecheck、ESLint／Prettier、23 項單元測試、8 項聲音瀏覽器測試（含真實 Web Audio 訊號）及 production SPA build 全部通過；仍待使用者確認新的音色。本次未修改 UI，沿用前次四種手機尺寸驗證。使用者已授權上傳此版本。
