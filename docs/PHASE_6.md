## 自己試用

1. 電腦開啟 http://127.0.0.1:9002/ ，先保持連線。
2. Chrome DevTools → Network → Offline，重新整理，完成一組並複製，確認仍能使用；測完切回正常網路。
3. 手機要使用部署在可信任 HTTPS 的同一版本：加入主畫面後，關閉 App、斷網、重新開啟並完成練習。檢查 iPhone Safari／Android Chrome 的畫面、捲動、音效與複製。

本機預覽僅綁定 127.0.0.1，不提供手機連入；尚未部署公開網站。手機的 127.0.0.1 指向手機自己，不能用來開啟電腦上的 App。一般區網 HTTP 也不能代替 HTTPS 的 Service Worker／安裝驗證。

## 限制與後續

- 第一次從未連線快取的裝置無法直接離線使用。
- 日文 Web Speech API 是否能離線播放取決於系統聲音；核心練習不依賴語音播放成功。
- 重新整理仍會清除當次作答，只保存設定；不新增歷史或同步。
- 尚待手機實機及正式 HTTPS 網址驗收，因此不宣告 Phase 6 全部完成。
