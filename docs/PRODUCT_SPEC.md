# 大家的日本語助詞練習 App

## 1. 產品定位

一款以《大家的日本語》課程進度為骨架的手機日文助詞練習 App。

產品不是電子課本，也不是傳統考卷。

核心體驗參考 Duolingo：

**打開 App → 按開始 → 立刻做題 → 得到簡單回饋 → 下一題。**

主要使用情境：

* 搭捷運
* 等車
* 排隊
* 工作空檔
* 睡前幾分鐘
* 任何只有 1～5 分鐘的零碎時間

使用者不需要每次設定課程、題型與助詞。

App 必須記住上一次的設定。

---

# 2. 第一版核心目標

V0.1 只做好一件事情：

> 讓使用者快速、大量、反覆練習《大家的日本語》的「助詞」。

第一版不做：

* 單字系統
* 文法系統

* 愛心

先把「助詞練習」做到非常順。

# 3. 核心設計原則

## 3.1 打開就能玩

首頁不能像設定頁。

不能要求：

課程 → 助詞 → 模式 → 題數 → 開始

正常使用流程必須只有：

**打開 → 開始**

---

## 3.2 設定要存在，但藏起來

首頁保留目前使用中的設定。

例如：

第 18 課
に・で
混合

但使用者不需要操作它。

想修改時才進入「練習設定」。

---

## 3.3 圖像化

視覺風格偏 Duolingo：

* 大按鈕
* 圓角
* 大面積留白
* Icon 為主
* 短文字
* 明確正確／錯誤回饋
* 一個畫面只做一件事

避免：

* 表格
* Checkbox 外觀
* 傳統 HTML Form
* 大量下拉選單
* 長篇文法說明

實際 Icon 使用 UI Icon Library，例如 Material Symbols，而不是直接使用 Emoji。

# 8. 非常重要的 Lesson 規則

課程篩選採取「嚴格課別」。

如果只選：

**第 18 課**

就只能出：

**資料庫中 lesson = 18 的助詞內容。**

不能因為使用者已經學到第 18 課，就混入第 1～17 課的助詞題。

如果勾：

**第 1～18 課**

才可以使用第 1～18 課的資料。

例如：

```text
lessons = [16, 17, 18]
```

就只能從 16、17、18 中取題。

`に`

`に・で`

`に・で・を・が`

# 10. 練習模式

V0.1 共四種。

## 模式 A：選助詞

最主要、也是預設模式。

例如：

```text
図書館（　）
日本語を勉強します。

[ に ]

[ で ]
```

答案：

```text
✓ で

動作場所
```

### 規則

此模式至少必須選擇兩個助詞。

因為如果只選 `に`：

每題直接一直按 `に` 就能答對。

所以：

```text
選助詞模式
→ selectedParticles.length >= 2
```

如果只有一個，不跳 Alert。

只顯示簡單提示：

「再選一個助詞」

開始按鈕不可用。

---

# 11. 模式 B：助詞用途

用來真正理解某個助詞。

例如使用者選：

`に`

題目：

```text
7時に起きます。

「に」在這裡表示？

[ 時間點 ]

[ 到達點 ]

[ 對象 ]

[ 存在地點 ]
```

答案：

```text
✓ 時間點
```

下一題可能：

```text
学校に行きます。
```

答案：

```text
✓ 到達點
```

再下一題：

```text
先生に質問します。
```

答案：

```text
✓ 對象
```

目的不是背「に」。

而是建立：

```text
に
├─ 時間點
├─ 到達點
├─ 存在地點
├─ 對象
└─ ...
```

用途模式允許選擇一個或多個助詞。

如果選擇多個，系統隨機挑其中一個助詞的例句。

---

# 12. 模式 C：找錯

顯示完整句子。

例如：

```text
図書館に本を読みます。

[ ✓ 沒問題 ]

[ 👀 有問題 ]
```

正確：

```text
✓ 找到了

に → で

動作場所
```

也必須存在真正正確的句子。

例如：

```text
学校に行きます。

[ ✓ 沒問題 ]

[ 👀 有問題 ]
```

答案：

```text
✓ 沒問題

に · 到達點
```

找錯題必須混合：

* 正確句
* 錯誤句

避免使用者無腦一直按「有錯」。

---

# 13. 模式 D：混合

把不同題型隨機混在同一組練習。

例如：

第 1 題：選助詞
第 2 題：用途
第 3 題：找錯
第 4 題：選助詞
第 5 題：用途

如果選擇至少兩個助詞：

混合：

* 選助詞
* 用途
* 找錯

如果只選一個助詞：

只混合：

* 用途
* 找錯

因為「選助詞」模式至少需要兩個候選助詞。

---

# 14. 題目畫面

頂部只保留：

```text
×      ███████░░░
```

* 左側：離開
* 中間：進度條

答題前不能出現完整句子語音播放按鈕。

原因：

語音可能直接暴露助詞答案。

# 15. 答題回饋

答案確定後，底部顯示簡單回饋。

答對：

```text
✓ 正確！

で
動作場所

🔊

[ 繼續 ]
```

答錯：

```text
✕ 不對

正解：で
動作場所

🔊

[ 繼續 ]
```

解析只使用非常短的「用途標籤」。

例如：

* 時間點
* 到達點
* 動作場所
* 存在地點
* 動作對象
* 對象
* 手段
* 起點
* 終點

V0.1 不顯示長篇文法課程。

---

# 16. 整句日文語音

每一道題目完成後出現：

`volume_up`

按下後播放「正確的完整日文句子」。

例如原題：

```text
図書館（　）日本語を勉強します。
```

正解為：

`で`

播放：

```text
図書館で日本語を勉強します。
```

如果使用者原本答錯，也只能播放修正後的正確句子。

可以不限次數重播。

語言設定：

```text
ja-JP
```

V0.1 使用瀏覽器 / 手機系統 TTS。

# 20. 一鍵複製給 AI

這是產品核心特色之一。

完成後按：

「複製給 AI」

直接把本次所有作答資料寫入 Clipboard。

格式必須適合直接貼給 ChatGPT、Claude、Gemini。

範例：

```text
請分析我這次的日文助詞練習。

請幫我：
1. 找出我真正不熟的助詞用法
2. 找出我容易混淆的地方
3. 用簡單白話重新教我
4. 最後針對我的弱點再出 5 題，不要先提供答案

【練習設定】
課程：第16、17、18課
助詞：に、で
模式：混合
題數：10
答對：7
答錯：3
正確率：70%

【作答紀錄】

1.
模式：選助詞
課程：第16課
題目：……
我的答案：に
正確答案：で
用途：動作場所
結果：❌

2.
模式：助詞用途
課程：第18課
句子：……
助詞：に
我的答案：到達點
正確答案：對象
結果：❌

...

【用途統計】
時間點：3/3
到達點：2/2
動作場所：1/3
對象：1/2
```

按下後顯示：

`✓ 已複製`

不跳新頁面。

# 21. 題庫架構

不要為每一種模式建立完全不同的題庫。

建立「助詞例句資料」。

例如：

```ts
interface ParticleExample {
  id: string
  lesson: number

  correctSentence: string
  sentenceWithBlank: string

  particle: string
  usage: string

  distractorParticles: string[]
  usageChoices: string[]

  wrongVariant?: {
    sentence: string
    wrongParticle: string
  }

  shortExplanation: string
  audioText: string
}
```

例如：

```ts
{
  id: 'l05-ni-arrival-001',
  lesson: 5,

  correctSentence: '学校に行きます。',
  sentenceWithBlank: '学校（　）行きます。',

  particle: 'に',
  usage: '到達點',

  distractorParticles: ['で', 'を', 'が'],

  usageChoices: [
    '到達點',
    '時間點',
    '動作場所',
    '對象'
  ],

  wrongVariant: {
    sentence: '学校で行きます。',
    wrongParticle: 'で'
  },

  shortExplanation: '到達點',
  audioText: '学校に行きます。'
}
```

同一筆資料可以生成：

* 選助詞題
* 用途題
* 找錯題

減少題庫重複。

---

# 22. 題庫的 Lesson 定義

`lesson` 代表：

**這個助詞用法在本 App 中被歸屬到《大家的日本語》的哪一課。**

不是：

「這句話所有單字第一次出現在哪一課」。

因此：

```text
lesson = 18
```

就只有選到第 18 課時才能出現。

---

# 23. 題目內容原則

不能大量複製教材原題、課文或官方音檔。

使用：

**《大家的日本語》的課程進度與助詞用法作為學習範圍，自己重新設計原創例句。**

原創句子應：

* 短
* 自然
* 適合初級程度
* 優先使用該課或之前已學過的單字與文法
* 一題只聚焦一個主要判斷點
* 避免答案模糊
* 避免同一句有兩個都可接受的助詞，除非題目刻意要教這個差異

# 32. V0.1 成功的真正標準

不是：

「功能做完」。

而是：

> 使用者在沒有任何提醒的情況下，空閒時會想自己打開 App 做 10 題。

如果首頁需要思考：

失敗。

如果設定太麻煩：

失敗。

如果答一題需要太多操作：

失敗。

如果解析太長：

失敗。

如果做完很難把結果交給 AI：

失敗。

整個產品最重要的是：

**低摩擦、快速回饋、反覆練習。**
